# S2 与 S4：学习指定算法与按计划学习

S2 触发条件：用户要求学习某个点名的算法或数据结构，例如「讲讲线段树」。
S4 触发条件：用户说「按计划开始学习」（start learning per plan）。S4 先选出条目，再执行 S2。
全程规则：写入任何路径之前先测试它是否存在；已存在的文件保留，替换必须先询问用户。所有代码一律使用 Rust。

## S2 流程

### 步骤 1：存在性检查

- 动作：用 `test -e` 检查 `数据结构与算法集/<算法名>.md`、`数据结构与算法集/索引.md`、`学习管理/学习进度.md`。
- 处理：算法笔记已存在时，不覆盖；先读取现有内容，只补写缺失的小节，并告诉用户。
- 完成标志：已确定算法笔记是新建还是补写，三个路径的存在状态均已记录。

### 步骤 2：确定范围与摸底

- 动作：确认算法的通用名称、别名与前置知识；用一两个小问题测一下用户的起点，前置知识不足时先补前置，再回到本算法。
- 完成标志：已确定算法名、别名清单与讲授起点。

### 步骤 3：按七段结构讲授（A5）

教学原则：像最好的老师那样，先具体后抽象；一次只讲一段，每段结束抛一个检验问题，答对再继续；多用类比与小数据手算；让用户预测下一步；绝不跳步。七段按下列编号顺序出现，不得调换。

#### 1. 引入问题

- 内容：给一道不会这个算法就很难做的真实题目，让用户先尝试，感受暴力做法的痛点。
- 完成标志：用户说出了暴力做法及其瓶颈。

#### 2. 手算直觉

- 内容：用一组很小的数据，一步一步手工推演算法如何工作，每一步写出当前状态。
- 完成标志：用户能预测推演的下一步。

#### 3. 形式化思想

- 内容：在直觉之后才给出正式定义、不变量与正确性理由，语言简短，不堆符号。
- 完成标志：用户能用自己的话复述核心思想。

#### 4. Rust 实现

- 内容：给出完整可运行的 Rust 代码，使用稳定版工具链与标准库，一份 `main.rs`，输入通过 `std::io` 读取，并逐段解释关键语句，以及其中用到的 Rust 语言特性（所有权、借用、迭代器等）。
- 完成标志：代码块标注为 Rust，且用户能指出每个主要函数的作用。

#### 5. 复杂度

- 内容：给出时间复杂度与空间复杂度，说明推导过程，并指出常见数据范围下是否够用。
- 完成标志：用户能根据数据范围判断能否使用该算法。

#### 6. 三个易错点

- 内容：恰好列出 3 个初学者最常踩的坑，每个配一个会触发它的小反例。
- 完成标志：列出 3 个易错点，每个都有反例。

#### 7. 练习阶梯

- 内容：给出 5 道题，由易到难排列，每题标注来源与难度；第 1 题是模板题，第 5 题要求组合其他知识。
- 完成标志：列出 5 道题，每题都有来源与难度。

### 步骤 4：写算法笔记

- 动作：读取 `assets/algorithm-note.template.md`，把讲授内容整理后写入 `数据结构与算法集/<算法名>.md`。前置字段含 `title`、`aliases`、`tags`、`progress`、`first_learned`、`last_updated`。`tags` 加 `algo/`、`ds/`、`rust/` 前缀；与相关题目笔记、相关算法笔记用 `[[双向链接]]` 互链。
- 完成标志：笔记存在，七个编号小节齐全，`tags` 与链接就位。

### 步骤 5：更新索引

- 动作：在 `数据结构与算法集/索引.md` 追加或更新该算法的一行（算法、状态、笔记链接）；若该算法有可复用的 Rust 模板，同时在 `数据结构与算法集/代码模板库.md` 追加。
- 完成标志：索引里有该算法一行，链接可点开。

### 步骤 6：调用 S3

- 动作：按 `references/s3-progress.md` 对本算法执行 S3，传入「讲授已完成」。
- 完成标志：S3 已走完，进度表中该算法状态已更新。

## S4 流程：按计划学习

### 步骤 1：存在性检查

- 动作：检查 `学习管理/学习指南.md` 与 `学习管理/学习进度.md` 是否存在。
- 处理：缺失时，按 `references/s0-init.md` 的步骤 2、6、7 补建，补建不覆盖任何已有文件。
- 完成标志：两个文件都存在。

### 步骤 2：选择条目

- 选择规则：按 `学习管理/学习指南.md` 从上到下的顺序，选出第一个未勾选（`- [ ]`）的条目；条目带子项时，取其中第一个未勾选的最内层子项；已勾选的条目一律跳过，状态为 `learning` 的未勾选条目会被再次选中，相当于继续上次的学习。
- 全部勾选时：告诉用户大纲已学完，建议做一次模拟赛（E4），不再执行后续步骤。
- 完成标志：已选出唯一一个条目，并告诉用户选中了哪个、为什么是它。

### 步骤 3：执行 S2

- 动作：对选中的条目执行上面的 S2 流程。语言基础类条目同样走 S2，标签使用 `rust/` 前缀。
- 完成标志：S2 的六个步骤全部完成。

### 步骤 4：更新勾选

- 动作：条目状态达到 `practiced` 或 `mastered` 时，把学习指南里该条目改为 `- [x]`；尚未达到则保持不勾选。
- 完成标志：学习指南的勾选与进度表状态一致。
