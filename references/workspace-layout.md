# 工作区布局（workspace-layout）

工作区根目录就是 Obsidian 仓库。导师负责创建并长期维护下表中的每一个目录与文件；用户只需提问。

## 目录与文件总表

| 路径 | 类型 | 用途（一句话） |
|---|---|---|
| `/`（工作区根） | 目录 | Obsidian 仓库根目录，所有知识库与管理文档都放在这里。 |
| `AGENT.md` | 文件 | 写给同一工作区内新会话的操作手册，由 S0 创建并同时触发两个知识库的初始化。 |
| `问题集/` | 目录 | 知识库【问题集】，保存用户咨询过的每道题的笔记。 |
| `问题集/索引.md` | 文件 | 【问题集】的索引笔记，按表格列出所有题目笔记及其难度、来源与标签。 |
| `问题集/<来源>-<题名>.md` | 文件 | 单题笔记，含 `title`、`difficulty`、`source`、`tags`、`date` 字段（E5），由 S1 写入。 |
| `数据结构与算法集/` | 目录 | 知识库【数据结构与算法集】，保存每个算法与数据结构的学习笔记。 |
| `数据结构与算法集/索引.md` | 文件 | 【数据结构与算法集】的索引笔记，列出所有算法笔记及其进度状态。 |
| `数据结构与算法集/<算法名>.md` | 文件 | 单个算法或数据结构的笔记，按七段课程结构书写，由 S2 与 S3 写入。 |
| `数据结构与算法集/代码模板库.md` | 文件 | E3 代码模板库，收录经过验证的 Rust 竞赛模板。 |
| `学习管理/` | 目录 | 存放学习指导与追踪类文档，与两个知识库分开，便于一眼找到。 |
| `学习管理/学习指南.md` | 文件 | 含 ACM 大纲 TODO 清单的学习指南，记录大纲来源链接、获取日期与核实状态（C3）。 |
| `学习管理/学习进度.md` | 文件 | 进度表，逐项记录每个知识点的状态（A7）、最近更新日期与笔记链接。 |
| `学习管理/复习队列.md` | 文件 | E1 间隔复习队列，记录每个题目或算法的下次复习日与当前轮次。 |
| `学习管理/错题本.md` | 文件 | E2 错题本，记录每次失败尝试的现象、根因与防再犯检查项。 |
| `学习管理/测验记录.md` | 文件 | E4 阶段自测与模拟赛记录，用于判断是否可以进入下一阶段。 |

## 五项已确认的扩展结构与落点

| 编号 | 扩展 | 落点 |
|---|---|---|
| E1 | 间隔复习 | `学习管理/复习队列.md` |
| E2 | 错题本 | `学习管理/错题本.md` |
| E3 | 代码模板库 | `数据结构与算法集/代码模板库.md` |
| E4 | 阶段自测与模拟赛记录 | `学习管理/测验记录.md` |
| E5 | 每道题的难度与来源字段 | 单题笔记的 `difficulty`、`source` 字段，并同步到 `问题集/索引.md` 的对应列 |

## 命名与链接约定

- 单题笔记文件名：`<来源>-<题名>.md`，来源与题名中的斜杠与冒号一律换成短横线。
- 算法笔记文件名：算法的通用中文名，别名写入 `aliases` 字段，保证 `[[双向链接]]` 能命中。
- 标签只写在 YAML 前置字段 `tags` 中，前缀固定为 `algo/`、`ds/`、`rust/`。
- 单题笔记与算法笔记必须互相用 `[[双向链接]]` 指向对方。

## 一致性要求（维护时逐项核对）

1. 索引笔记里的每一行都能点开对应笔记，笔记存在就必须出现在索引里。
2. 学习指南中的每个条目在学习进度里都有一行，状态与勾选一致。
3. 进度状态为 `practiced` 或 `mastered` 的算法，必须在复习队列里有记录。
4. 错题本中的每一条都链接到题目笔记，题目笔记的「复盘」小节反向链接到错题条目。
5. 任何文件只做行级追加或局部修改；整文件重写属于替换，必须先询问用户。
